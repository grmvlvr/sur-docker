# Запуск СУР в Docker

Нужен Docker Desktop (режим **Linux containers**).

Первая сборка может занять 15–40 минут: качаются образы Node и .NET.

В этой папке выполните:

```powershell
docker build -t sur:latest .
docker run --rm -p 8080:8080 -v sur-data:/app/App_Data sur:latest
```

Сайт: http://127.0.0.1:8080/

Пароль у всех: `sur-demo`  
Примеры логинов: `owner@sur.local`, `admin@sur.local`, `director@sur.local`

Остановка: `Ctrl+C` в окне, где запущен `docker run`.
